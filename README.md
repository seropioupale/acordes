# Entrenador de Acordes

Piano virtual para aprender acordes, grados y progresiones: 19 tipos de acorde, los acordes de cada tonalidad mayor y menor, diez progresiones clásicas y siete tipos de ejercicio. Se puede añadir a la pantalla de inicio del móvil y funciona sin conexión.

Abrir: https://seropioupale.github.io/acordes/
